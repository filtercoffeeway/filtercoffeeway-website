Program description

This is a personal errand-assistant messaging program operated by Mahesh. The operator texts a short instruction to the program number; the application replies with a summary of what it is about to do and a spending limit, and waits for confirmation. On confirmation it places an automated phone call to a business to place an order for pickup, then sends one message reporting the result.

Who can participate

The operator is the sole recipient. The destination number is fixed in the application’s configuration. Messages from any other number are ignored and receive no reply. The program is not open to the public and does not accept sign-ups.

Consent

Consent is given by the operator entering their own mobile number into the application’s configuration. There is no web form, paper form, QR code, or keyword sign-up, because no one other than the operator is ever messaged.

Message frequency

Message frequency varies and is determined entirely by the operator, who starts every conversation. Typically fewer than ten messages per day, and often none. The program never initiates contact.

Cost

Message and data rates may apply. The program itself is free.

Opting out

Reply STOP to any message to end all messaging. A single confirmation message will be sent, after which no further messages are sent.
